# 手搓 Godot 美术 UI 的思路总结

> 适用范围：火影世界 Flash → Godot 的界面还原。本文只讲美术与交互的做法，不涉及协议对接。

**一句话：一切以原版为准 —— 先数清原版有几种状态，就有几个状态容器，脚本只负责"显示哪一个"，逻辑只负责"告诉我是哪一种"。**

---

## 一、制作流程

### 1. 对原版，不猜

先用 ffdec 反编译出来的 AS3 源码 + SWF 时间轴，确认这个控件到底有几种状态、每种状态长什么样、尺寸是多少。

靠肉眼猜布局是踩过坑的（猜错过一次，最后还得回源码改），**源码是准绳**。

### 2. 几个状态就建几个 Control 容器

- 原版只有「未达成 / 已达成」两种 → 建两个容器：`状态_未达成`、`状态_已达成`
- 三个状态（手里剑就是：未修炼 / 已修炼 / 已达瓶颈）→ 三个容器

所有容器**同级摆放、位置对齐**，由父节点决定整体位置，容器之间只换内容不换坐标。

### 3. 容器里放该状态自己的图

每个状态用哪张贴图就放哪张，不做二次加工，保证和游戏里一模一样。

### 4. 写一个切换脚本

脚本里只暴露一个入口方法（`设置状态(索引或名字)`），内部逻辑就一句话：

> 目标容器 `visible = true`，其余全部 `false`。

**默认显示"未达成"那个容器。**

### 5. 逻辑侧只连一个点

后端判断"达没达成"之后，调一次 `设置状态()` 就完事，不用碰任何贴图、坐标、颜色。

美术和逻辑彻底解耦 —— 这是整套做法最大的收益。

---

## 二、什么时候**不用**容器（重要分叉）

| 情况 | 做法 | 原因 |
| --- | --- | --- |
| 状态之间是**同一张图**，只是变灰 / 变暗 / 换色调 | **不要建容器**，一个节点 + `modulate` 或去饱和 shader | 省资源，不会产生重复贴图 |
| 状态之间是**不同贴图**，或排版结构不一样（多一个角标、少一行说明） | **用容器切换** | 别在运行时改坐标改贴图，那种代码难维护也容易漏 |

一句话判断：**"变个色就能表达" 就用 modulate，"要换张图 / 要挪位置" 才开容器。**

---

## 三、状态里带数字 / 文字的怎么处理

**在对应状态的容器下面挂子节点显示**，而不是用一个全局文字节点靠脚本挪位置。

好处：每个状态的文字位置、字号、颜色都能在编辑器里单独调，改一个不影响另一个。

配套要求：

1. **一个数值一个 Label**
   不要把 攻击 / 距离 / 几率 合并成一大段文字。拆开后每个都能单独选中微调间距。

2. **所有文字统一：黑色描边 3，阴影显式清零**
   `font_outline_color = 00000000` 之外，每个文字节点都要**显式写一行** `font_shadow_color = 00000000`。
   不能靠"默认就是没有阴影"——要在 Inspector 里看得见这行覆盖，才符合原版发光观感，也方便后续排查。

3. **数值不由美术算**
   容器只负责"这个状态下显示什么"，具体数字从逻辑传进来，填进对应的 Label。

---

## 四、边界说明

我这边只做**美术还原 + 按钮交互**，不碰协议。

- 所有对外动作（点修炼、点突破、点登录）都以**信号**发出去
- 走现有的 `request_*` 接口，我不新增、不改服务端调用
- 缺什么运行时数据（背包数量、战斗数值）在代码里留注释标出来

## 五、已经踩过的坑，省得重复踩

- **F6 单独运行页面时就必须是正确的默认态。**
  别依赖外部窗口来初始化，`_ready` 里自己刷一遍。
  （实例：第一页的"上一页"箭头要一进去就是灰的，而不是点一下才变灰。）

- **按钮保持原版尺寸。**
  `StyleBoxTexture` 的 `texture_margin` 设成 7，会悄悄把 22px 高的按钮撑成 28px，哪怕你写了 `custom_minimum_size(61, 22)`。
  必须把 margin 归零，然后**运行时打印 `size` 验证**，不能只看编辑器。

- **每页自带脚本副本。**
  箭头按钮交互、去饱和 shader 这类共用脚本，每页复制一份到该页自己的脚本目录，交付的包是自包含的，拖进工程就能跑。

- **场景在磁盘上改过，编辑器里要重新加载。**
  否则看到的还是旧缓存，会误判"改了没生效"。

## 六、标准结构示意

```
图标控件 (Control)
├── 状态_未达成 (Control)        ← 默认可见
│   ├── 图标 (TextureRect)       ← 未达成那张图
│   ├── 等级 (Label)             ← 该状态自己的文字，位置单独调
│   └── 说明 (Label)
├── 状态_已达成 (Control)        ← visible = false
│   ├── 图标 (TextureRect)       ← 已达成那张图
│   ├── 等级 (Label)
│   └── 说明 (Label)
└── 状态_已达瓶颈 (Control)      ← visible = false
    └── ...

脚本：设置状态(索引) → 目标容器 visible=true，其余 false
逻辑：判断达成情况 → 调一次 设置状态()
```
