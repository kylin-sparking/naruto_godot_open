# 结印页 —— 融合进主项目时的注意事项（给融合方 AI）

## 一句话

融合 `场景/界面/窗口/人物/页面/结印页.tscn` 时，**不要再套「统一页面字号 / 统一按钮尺寸」这类一刀切逻辑**。
本页 224 个节点里有 **41 组文字描边、41 处透明阴影、14 处字号、5 处颜色、2 处按钮尺寸**都是作者逐一手调的，
一刀切会把它们全部冲掉 —— 之前的 八门 / 写轮眼 / 柔拳 / 寄坏之术 / 轮回六道 五个页面就是这么变的。

---

## 一、已经踩过的坑（请勿重演）

主项目 `脚本/界面/窗口/人物窗口.gd` 里的 `统一页面字号()` 目前是**旧的一刀切写法**：

```gdscript
static func 统一页面字号(窗口, 节点: Node) -> void:
	for 子节点 in 节点.get_children():
		if 子节点 is Label:
			窗口._configure_label(子节点 as Label, 11, Color("#f5ead6"))      # 无条件覆盖
		elif 子节点 is RichTextLabel:
			(子节点 as RichTextLabel).add_theme_font_size_override("normal_font_size", 11)
		elif 子节点 is Button:
			var 按钮 := 子节点 as Button
			if not 按钮.flat:
				窗口._configure_standard_button(按钮)      # 无条件设成 57×22
		统一页面字号(窗口, 子节点)
```

**它造成的实际后果（已实测）**：

| 页面 | 被冲掉的颜色 |
| --- | --- |
| 八门页 | 207 处 `font_color` 里 **15 处彩色**被刷成米白 |
| 写轮眼页 | **191 处全部**被刷成米白 |
| 柔拳页 | **105 处全部**被刷 |
| 寄坏之术页 | **15 处全部**被刷 |
| 轮回六道页 | **58 处全部**被刷 |
| 五个页面合计 | **47 个按钮**被强制改成 57×22 |

## 二、正确写法（场景优先）

只给「场景里没设过」的控件补默认值，场景里设过的一律不动：

```gdscript
static func 统一页面字号(窗口, 节点: Node) -> void:
	for 子节点 in 节点.get_children():
		if 子节点 is Label:
			var 标签 := 子节点 as Label
			var 有色: Variant = 标签.get("theme_override_colors/font_color")
			var 有字: Variant = 标签.get("theme_override_font_sizes/font_size")
			if 有色 == null and 有字 == null:
				窗口._configure_label(标签, 11, Color("#f5ead6"))
			else:
				if 有色 == null:
					标签.add_theme_color_override("font_color", Color("#f5ead6"))
				if 有字 == null:
					标签.add_theme_font_size_override("font_size", 11)
		elif 子节点 is RichTextLabel:
			var 富文本 := 子节点 as RichTextLabel
			if 富文本.get("theme_override_font_sizes/normal_font_size") == null:
				富文本.add_theme_font_size_override("normal_font_size", 11)
		elif 子节点 is Button:
			var 按钮 := 子节点 as Button
			# 场景里写了 custom_minimum_size 的按钮不动（如 25×24 的关闭按钮）
			var 有尺寸: Variant = 按钮.get("custom_minimum_size")
			if not 按钮.flat and (有尺寸 == null or (有尺寸 as Vector2) == Vector2.ZERO):
				窗口._configure_standard_button(按钮)
			elif 按钮.get("theme_override_font_sizes/font_size") == null:
				按钮.add_theme_font_size_override("font_size", 11)
		统一页面字号(窗口, 子节点)
```

三条关键差异：

| 控件 | 旧写法 | 正确写法 |
| --- | --- | --- |
| `Label` | 无条件覆盖颜色 + 字号 | 只补场景里缺的那一项，设过的不动 |
| `RichTextLabel` | 无条件设 11px | 场景里没设过才补 11 |
| `Button` | 所有非 flat 按钮套 57×22 | 已有 `custom_minimum_size` 的**跳过** |

## 三、结印页里「不能被覆盖」的东西（实测数字）

| 项目 | 数量 | 说明 |
| --- | --- | --- |
| `theme_override_colors/font_outline_color` | **41** | 黑色文字描边，本页核心观感 |
| `theme_override_constants/outline_size` | **41** | 描边粗细（3px） |
| `theme_override_colors/font_shadow_color` | **41** | 按作者要求设为透明 `Color(0, 0, 0, 0)` |
| `theme_override_font_sizes/font_size` | **14** | 其中 **12 处是 8px**（熟练度数值那种小字） |
| `theme_override_colors/font_color` | **5** | 4 处米白 `#f5ead6` + 1 处橙 `#e88300` |
| `custom_minimum_size` | **2** | 含 25×24 的关闭按钮，被改成 57×22 会顶出版面 |
| 主题引用 | 1 | `素材/界面/原版窗口/人物/结印/宋体文字/结印字体.tres`（宋体 12px） |

节点规模：`Label` 65、`ProgressBar` 60、`Control` 40、`TextureRect` 39、`TextureButton` 12、`Button` 4、`Panel` 3。

### ⚠️ 两个特别容易踩的点

**1. 12 个 `印式按钮/印N/印式NN` 是 `TextureButton`，不是 `Button`。**
`子节点 is Button` 这个判断**不包含** `TextureButton`，所以现在的统一逻辑碰不到它们 —— 这是运气好。
但如果有人图省事把它改成 `is BaseButton`，这 **12 个印的图标按钮会被套上按钮皮肤，位置和尺寸全乱**。
**请保持用 `is Button`，不要放宽到 `BaseButton`。**

**2. 12 个 `熟练度值数值` 的 `font_size = 8` 最容易被「统一成 11」。**
它们挤在 40px 宽的小格子里，字号一变就会撑破进度条。这一项必须保住。

## 四、融合完成后请逐项自检

1. 弹窗里 12 个「熟练度值数值」仍是 **8px**，没有变大、没有撑破
2. 所有文字仍有**黑色描边**（`outline_size = 3`），不是光秃秃的无描边字
3. `提升结印` / `帮助` / `开始提升按钮` / `自动提升按钮` 的**宽度没变**（不是统一的 57×22）
4. 弹窗右上角「关闭按钮」仍是 **25×24**
5. 12 个「熟练度值数值」分别是：
   `600 / 1500 / 4000 / 6500 / 9000 / 12000 / 15000 / 18000 / 25000 / 36000 / 42000 / 50000`
6. 弹窗还是**默认收起**的，点「提升结印」才滑进来，点「关闭」滑出去

## 五、另外两条注意事项

### 1. `project.godot` 里不要有这两行

```gdscript
rendering/2d/snap/snap_2d_transforms_to_pixel=true
rendering/2d/snap/snap_2d_vertices_to_pixel=true
```

如果主项目里有，**请删掉**。这两行会让 2D 顶点吸附到整数像素，
**写轮眼页的阶段切换动画会因此明显抖动**（已实测；社区对高清/平滑素材的结论也是这两个选项应该关掉）。
它们是给像素画游戏用的，本项目的素材是高清缩放动画，开了只会帮倒忙。

### 2. 结印页的资源引用已经全部收在本目录内

已校验：**场景指向 `人物/结印/` 之外的资源引用 = 0**。
打包时把 `素材/界面/原版窗口/人物/结印/` 整个文件夹拷走即可，
**不需要**额外带 `通用控件/`、`柔拳/`、`轮回六道/` 下面的东西。

本页用到的 3 个脚本，全在 `素材/界面/原版窗口/人物/结印/脚本/`：

| 脚本 | 作用 |
| --- | --- |
| `结印切换.gd` | 12 个印的点击切换、选中框/默认框/数值面板的显隐 |
| `提升结印阶数弹窗滑动动画.gd` | 弹窗滑入滑出 + 12 阶熟练度上限表 + `刷新熟练度()` |
| `结印指针跟随.gd` | 指针按现实时间指向对应的印（只认小时，不掺分秒） |

素材同样都在结印目录：印式 01~14、印点、印点连线、指针、新结印阵、结印阵、`印buff图标/印1~12`、
`宋体文字/结印宋体.TTC` + `结印字体.tres`、`结印子面板.png`、`结印关闭按钮.png`。
