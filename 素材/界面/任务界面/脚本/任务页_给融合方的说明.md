# 任务页（小地图下的任务追踪栏 + 任务窗口）—— 融合进主项目时的注意事项

## 一句话

本包交的是**美术端**：追踪栏的底、标题条、两个页签的字（位置 + 渐变 + 描边）、折叠钮两态、
任务窗口的可点击文字与悬停上色。**协议与玩法逻辑不在本包内**，仍然走主项目已有的 `request_*`。

## 二、三条「顺手清理」会把页面弄坏的引擎事实（已实测，别改回去）

**1. `Button` 在 Godot 4.7 里没有 `vertical_alignment`。**
ClassDB 实测属性只有 `alignment` / `icon_alignment` / `vertical_icon_alignment`。
在 `.tscn` 里写 `vertical_alignment = 0` **不报错也不生效**（无效属性被静默丢弃）——
之前就是这么"改了没效果"的。文字恒在「按钮矩形扣掉皮肤上下边距」之后居中，
所以想让墨迹往上走，**唯一的旋钮是皮肤的 `content_margin_bottom`**：加 4 → 上移 2。
本页两个页签用的就是 `StyleBoxEmpty_quest_tab_text`（`content_margin_bottom = 4.0`），
把字从第 7 行抬到原版的第 5 行。**删掉这份皮肤 = 页签文字整体下沉 2px。**

**2. `canvas_item` 着色器里 `fragment()` 的 `VERTEX` 是**变换后**坐标（≈视口空间），不是控件局部坐标。**
所以渐变的 y 必须**在 `vertex()` 里取局部 y 存进 `varying`**（现在就是这么写的）。
本页签全局 y≈177，若直接用 `VERTEX.y/19` 会被 clamp 成 1 → 渲出一整片末端色 #FF9C43，
渐变整条消失。并排全景图里看不出来，只有 8× 单件放大能看出来。
原版的渐变盒是 `createGradientBox(宽, textHeight+4, PI/2)`、锚在皮肤自己的 (0,0)
（`GradientTextField.as:178/193`），所以必须用局部 y。

**3. 两个页签共用场景里同一份 `ShaderMaterial`。**
运行期改 uniform 会互相串台，`小地图面板.gd` 的 `_绑页签()` 里对每个按钮各取一份
`.duplicate()`。融合时若把这段"优化"掉，切页签会两边一起变色/变灰。

## 四、几何真值（照原版，改之前先对着这张表）

追踪栏整体：宽 **175**，贴在 `小地图区域` 右上锚点，`offset_top = 178`，展开高 **180**（收起 22）。
原版来源 `QuestTrackerWindow.as:123-164`（twip 已 ÷20 换算成像素）：

| 件 | 位置/尺寸 | 原版依据 |
|---|---|---|
| `TitleSkin` 标题条 | (0,0) 175×23 | `任务追踪标题.png` 实测 175×23，body alpha≈0.74–0.82，会和小地图透出混合 |
| 页签「当前任务」 | x=**20**, y=3, 54×19 | `_acceptBtn.x=20`，`GradientTextField(54)` |
| 页签「可接任务」 | x=**90**, y=3, 54×19 | `_notAcceptBtn.x = _acceptBtn.x + 70` |
| 折叠钮 `BranchButton` | x=**153**, y=2, 18×18 | `x = _width - width - 4` |
| 行推进 | **20px**/行 | Flash 12px 宋体 textHeight=15（由页签高 19=textHeight+4 反推）+ LEADING 5；Godot 宋体 12px 字体高 13 ⇒ `line_separation = 7` |

字体：宋体 **12px**、黑描边 `outline_size = 3`、阴影透明 —— 与其余页一致，本页没有 8px 小字。

## 五、融合完成后请逐项自检（跑一遍就能看出来）

1. 追踪栏有**从上到下的半透明灰底**（不是纯色块、也不是没有底），底部透出小地图
2. 两个页签的字是**黄→橙渐变**（顶部 #FDF570、底部 #FF9C43），不是一整片橙色；带黑描边
3. 页签字的**顶边在第 5 行**（原版位置），没有整体下沉 2px
4. 点折叠钮：展开态显示**减号**图、收起态显示**加号**图，收起后只剩 175×22 的标题条
5. 切「可接任务」页签时，另一个页签**不跟着变色**
6. 任务窗口里 `上文本/下文本` 的任务名是**可点击**的，鼠标悬停变 **红**（原版 `#ff0000`，
   `StructuredText.as:719/723/771`），按下变按下色；两个面板各自悬停不互相染色
