# 素材目录说明

本目录在开源仓库里**只保留代码类文件**：

- `*.gd`：人物秘术页等页面脚本（写轮眼、轮回六道、结印、柔拳、手里剑、寄坏之术、任务窗口等）
- `*.tres`：全局主题、页面主题、字体资源定义
- `*.gdshader`：去饱和、红色描边、圆形裁切等着色器
- `*.md`：这些页面的开发说明
- `界面/simsun_原版.ttf.import`：全局字体的导入参数（`antialiasing=0`，保证 12px 宋体数字清晰）

**图片、序列帧、字体本体、音频不随仓库提供。**不要删除上面这些代码文件，否则场景会加载失败。

## 需要补回的素材

**推荐：** 到火影世界开源单机交流群文件下载 `素材.zip`（约 1.1GB），解压到项目根目录，得到本目录的图片/字体/音频。
如果解压覆盖了这个 `README.md`，执行 `git checkout -- 素材/README.md` 恢复仓库版本。
压缩包内是中文文件名，请用 Windows 资源管理器、7-Zip 或 Bandizip 解压；Git Bash 自带的 `unzip` 可能显示乱码。

也可以从完整的本地开发目录或上游 2.2.3 一键端取得，保持原路径：

```text
素材/界面/                          UI 切片、按钮、底纹等
素材/物品/原版/                     物品图标
素材/角色动画/{玩家,怪物,宠物,非玩家角色}/   序列帧
素材/地图/{地图名}/                 小地图、背景、地图块、物件
素材/特效/                         传送门等特效序列帧
素材/技能/                         技能图标与 effect/hit 帧
素材/状态图标/
素材/音效/
```

字体与登录器媒体（这些原先也不在 git 里）：


## 随仓库分发的运行期目录

| 目录 | 来源 | 说明 |
|---|---|---|
| `场景/生成/` | 已随仓库提供，也可用 `开发工具/烘焙当前地图.gd -- --all` 重新生成 | 运行时加载的烘焙地图 |
| `运行时/python/` | 已随仓库提供（官方 Python 3.13 embeddable，Windows x64） | `启动游戏.bat`、在线门、GM 控制台使用 |

`运行时/python/python313._pth` 里如果带 `..\..\tools` 一行，请删掉，避免服务端意外 import 上游 2.2.3 的工具（仓库里的这份已删）。

## 补完后

```bash
Godot --headless --path . --import
```

首次导入会生成 `.godot/` 缓存，耗时较长；之后再运行项目。

可用 `开发工具/查证素材缺失.py` 检查缺失项；与界面/地图相关的离线门在素材缺失时会失败，这是预期行为。
