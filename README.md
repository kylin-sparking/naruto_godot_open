# 火影世界 · Godot 重制版

> 用 **Godot 4.7** 重构的《火影世界》2.2.3 客户端，附带本地服务端、数据导出/导入工具和回归测试。

本项目由**火影godot复刻组**开发，与已停运十多年的原版无关，也**不提供任何原版美术、字体、音频素材**。
仓库只包含代码、场景、数值数据和开发工具；运行前需要自备素材，见「素材」一节。

火影世界开源单机交流群：1097398812（已满），看入群问题，加新群就是。

- **2.2.3 Flash 版**：九月（火影开源复刻组）开发并开源。本项目的客户端逻辑、界面布局和数值口径以其为参照。

- **本次 Godot 正式开源贡献者**：火影godot复刻组：流尘浅林、李肆夜、宇智波风羽。

完整的来源、第三方组件与许可说明见 [`NOTICE.md`](NOTICE.md)。

## 项目状态

客户端已接入登录、选角/创角、地图与 HUD、人物、背包、仓库、忍术、结印、写轮眼、轮回六道、八门、寄坏之术、柔拳、手里剑、宠物、任务、副本、组队、好友、家族、商城、活动、修炼/挂机、战斗等窗口与协议。
在线状态下，角色属性、背包、技能、宠物、战斗、掉落、副本、挂机、商城、社交和奖励以本地服务端回包为准；客户端不在本地扣费或重复发奖。

在完整开发目录中，截至 2026-10-30，离线回归门全量 **189 条**（`开发工具/跑全部离线门.py 1 189`）为 **189 绿 / 0 红 / 0 挂**；本仓库缺素材时，界面/地图相关用例会按「已知限制」失败。技术文档见 [`docs/`](docs/)；逐轮开发记录属于内部资料，不随仓库发布。

## 仓库包含 / 不包含

**包含**

- `脚本/`、`场景/`、`数据/`、`数据_扩展/`、`服务端/`、`开发工具/`、`测试/`、`真值/`、`docs/`
- `素材/` 下的 **`.gd` / `.tres` / `.gdshader` / `.md`**（页面脚本、主题、着色器和说明，属于代码而非美术）

**不包含（需要自备）**

- `素材/` 下的图片、序列帧、字体、音频（完整开发目录约 1.3GB）
- 登录器媒体：BGM、背景视频、音乐开关图标
- `场景/生成/` 烘焙地图（运行时真正加载的是这里的 `地图_<id>_烘焙.tscn`）
- `运行时/python`（服务端与启动脚本使用的 Python 解释器）
- 像素比对基线（原版界面截图、地图基准图，需本地自备）
- `.godot/` 导入缓存（首次打开 Godot 时自动生成）

因此，**直接 `git clone` 无法运行**。补素材的步骤见下。

## 快速开始

### 1. 环境

- **Godot 4.7.x**（标准版即可，项目只使用 GDScript）
- **Python 3.13**（运行本地服务端与部分工具；可用官方 embeddable 版放到 `运行时/python`）
- **Node.js**（仅在重新导出原版数据/素材时需要）
- Windows（启动脚本和部分工具面向 Windows；项目主体跨平台）

### 2. 补回素材与运行时

从完整的开发目录或上游 2.2.3 一键端取得文件，按原路径放回：

```text
素材/界面/...                     UI 切片、主题依赖的图片
素材/物品/...                     物品图标
素材/角色动画/...                 玩家/NPC/怪物/宠物序列帧
素材/地图/...                     小地图、背景、地图块、物件
素材/特效/、素材/技能/、素材/音效/
素材/界面/simsun_原版.ttf         全局 UI 字体
素材/界面/原版窗口/人物/柔拳/宋体文字/SIMSUN.TTC
素材/界面/原版窗口/人物/结印/宋体文字/结印宋体.TTC
素材/界面/登录器/登录器BGM.mp3
素材/界面/登录器/背景循环_1080p.ogv
素材/界面/登录器/音乐开.png、音乐关.png
场景/生成/                        168 张地图的烘焙场景
运行时/python/                    Python 3.13 embeddable
```

逐项说明见 [`素材/README.md`](素材/README.md)。

### 3. 导入并启动

```bash
Godot --headless --path . --import
Godot --path .
```

入口场景：`场景/界面/登录界面.tscn`。

### 4. 启动本地服务端

```bash
python 服务端/runtime/tools/fake_flash_server.py
```

默认监听 **18684**（Flash TCP）；网页入口 `http://127.0.0.1:18680/gm/index.html` 为 GM 控制台，详见 [`服务端/README.md`](服务端/README.md)。

Windows 下也可以直接双击 `启动游戏.bat`：它会先启动夹具服务端，再启动 Godot。该脚本要求 `运行时/python` 已就位；Godot 优先用环境变量 `NARUTO_GODOT`，否则用 PATH 里的 `godot`。

## 目录结构

```text
.
├─ 场景/            登录、地图、界面窗口与页面（.tscn）
├─ 脚本/            单例、地图、角色、界面逻辑
├─ 数据/            从 GameData.dat 导出的数值表、地图与动画元数据
├─ 数据_扩展/       可叠加的数据覆盖层
├─ 素材/            代码/主题/着色器随仓库；图片、字体、音频需自备
├─ 开发工具/        导出、导入、烘焙、截图、跑门等工具
├─ 测试/            离线门、在线门与回归夹具
├─ 真值/            从原版客户端/AS3 取到的界面与数值真值
├─ 服务端/          本地 Flash 协议服务端（沿用上游 2.2.3）
└─ docs/            体系真值、方法论等技术文档
```

## 测试

离线全量门：

```bash
python -X utf8 开发工具/跑全部离线门.py 1 189
```

需要完整素材、字体和 `场景/生成/`；缺素材时，和界面/地图相关的用例会失败。

在线门：

```bash
powershell -ExecutionPolicy Bypass -File 开发工具/跑在线用例.ps1
```

需要先在 18684 起服务端。在线门按条目使用隔离夹具，不会写日常存档。

## 数据来源

- `数据/` 由 `开发工具/导出*.py` / `*.mjs` 从 `服务端/runtime/www/act_web_nya_208_isolated/dat/GameData.dat` 导出。
- `GameData.dat` 随上游 2.2.3 提供，仅用于本地单机/联机模拟。
- `数据_扩展/*.json` 会在运行时递归合并到同名数据上，`数据/` 保持只读。
- 素材导入、地图烘焙和动画索引重建的入口都在 `开发工具/`。

## 已知限制

- `素材/` 二进制不进仓库，clone 后不能直接运行。
- `场景/生成/` 不在仓库中，地图必须先用烘焙工具生成。
- 像素比对基线不随仓库提供；运行像素比对门前，请从开发目录把对应基线放回本地。
- 逐轮编年史、交接单、报修单、体检报告和一次性探针脚本属于内部资料，不随仓库发布。
- 无头（`--headless`）模式的视口尺寸和帧率不代表实机；截图类工具不能加 `--headless`。
