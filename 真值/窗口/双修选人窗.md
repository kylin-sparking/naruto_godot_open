  翻页箭头 = `素材/界面/专用控件/分页上一页|下一页_{悬停,按下,灰}.png`（10-18 逐像素验过 == 通用控件原图 ±30/−40，不符像素 0）。

## ⑪ 三条本轮踩到、会复发的 Godot 坑

1. **无头 `root.size` 必须在跑起来的第一帧之后再设**。在 `_initialize` 那一层设会被启动流程顶回
   默认的 **64×64**（探针实测：设完立刻 `await process_frame` 读回来还是 (64,64)；跑过一帧再设才落到
   (960,560)）。64×64 时视口拾取整体失效：`mouse_entered` 不来、`BaseButton` 按下时因为
   `is_hovered()==false` **连 `pressed` 都不发** ⇒ 所有「真点」判据整批假红，
   而写 `pressed.emit()` 的门整批假绿。两道门都配了一条量具自检钉这个数。
2. **`TextureButton` 是 `BaseButton` 的子类，不是 `Button` 的子类** ⇒ `get_node("X") as Button`
   对它是 null，表现成 `Invalid access to 'pressed' on a base object of type 'Nil'`。
   接线与门里一律 `as BaseButton`（要读皮就 `as TextureButton`）。
3. **GDScript 的 `%` 结合得比 `+` 紧**：`"…%d…" + "…%s…" % [三值]` 只把**后半截**当格式串 ⇒
   占位符数量对不上时整条消息原样打出来（日志里那串没替换的 `%d` 就是这个）。
   拼接后要 `(A + B) % [...]` 整体括起来。
