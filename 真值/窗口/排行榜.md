## ⓪ 六条会影响整页的先决口径

**① 只有 1346，没有 2329。** 旧端口把排行榜挂在 `2329` 上 —— 那条是跨服**充值**榜
（`ChargeRankInfo` 列表），与 23 个榜单无关 ⇒ 服务端发的 `1346` 从来没被读过，玩家点开一片空白。
`2329` 本工程**不发也不接**（跨服充值窗未移植），`后端连接.gd` 里连常量都不留。

**② 上行三段：`"0:<menuId>:<1|0>"`。** 最后那格 bool 的真值 = 原版 `requestListData:106` 的
`!renJieBtn.enabled`，而 `changeTab(p)` 里 `renJieBtn.enabled = (p != 0)` ⇒ **flag = (p == 0)**：
忍界榜(p=0)⇒`1`、同级榜(p=1)⇒`0`。服务端字段叫 `bJiangHu`、客户端叫 `renJieBang`，名字反着来，别按名字猜。
少写那一格 ⇒ 服务端当畸形帧丢（门里钉 `0:0:1` / `0:2:0` 两条实串）。

**③ 回帧三种 cmd 的读序互不相同**（逐条照解码器抄，不猜）：
cmd0 = `1346:0:<charId>:<cnt>:<title@…|->`（头顶徽记，只解不画，画法挂 #87）；
cmd1 = `1346:1:<tabId>:<true|false>:<rank>:<行>`；cmd2 = `1346:2:<tabId>:<rank>:<行>`（**少一格 bool**）。
行 = `serverId&charId&name&petUid&value`，`@` 连行，空表 `-`。

**④ 「你的当前排名」不吃服务端那个 `rank`。** `onPaiHang_searchResult:86-92` 把它丢了，
名次是客户端**扫整张表找自己**（`queryMyRank:86-101`，`charId == stats.id` ⇒ 下标+1，找不到 ⇒「未上榜」）。
"我的角色 id"只能取 `BackendConnection.character_id`（`player_stats` 里**没有 `id`**，取它恒 0 ⇒ 人人未上榜）。

**⑤ 翻页是三种态，不是两种。** 未回帧 = 构造期 `PageComponent(50,10)` ⇒「1/5」且下一页/末页**亮着**、
一行不画；空表回帧 = `reset(0,10)` ⇒「1/0」四枚全灰、一行不画；有帧 ⇒ 真行数。
判"有没有回帧"用 `has("rows")`，**不能用行数是否为空**。
本榜回帧必把页序打回第 1 页（`setData:366` 那句 `reset`）；按 menuId 分格存帧 ⇒ 别的榜的回帧不动当前页。

**⑥ 23 条里只有 menuId 0（等级排行榜）没有 `tongDesc`** ⇒ 只有那一榜藏掉「同级榜」页签；
只有 menuId 2（宠物身价榜）`showType=1` ⇒ 列头第二列变「宠物主人」。`menuId` 条内本来没有，
是**键的数值**（行序 = 键数值升序），端口只在 `duplicate` 副本上补键，不许污染原表。

## ② 染色与选中态

## ③ 重开与换榜的态

每次开这扇都**重新 build**：关窗 `onCloseBtnClick:79-84` 先 `destroy()`，再进时 `createRankMenu:328-337`
默认选中第 0 条 ⇒ 重开必回「等级排行榜 / 忍界榜 / 第 1 页」，**不记**上次看的是哪条
（原版另有 `JueDouManager.rankIndex > 0` 那条从决斗窗跳进来的入口，本工程决斗窗未接，恒走默认）。
点左侧榜单 = `__selectRank:262-266` → `selecteRankMenu:230-254` 末尾那句 `__onRenJieBtnClick(null)`
⇒ **换榜一定退回忍界榜那一页**，并清掉行、发一发 `0:<新menuId>:1`。
