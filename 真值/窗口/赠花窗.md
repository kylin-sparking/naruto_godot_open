时间那一列的档位（`MarryZengHuaLogCell:116-137`）—— ⚠ **`sendTime` 是「离现在多少秒」，不是分钟、更不是墙上时钟**：
`:116` `if(_loc3_ < 60)` ⇒「刚刚」；`:122` `分 = _loc3_/60`，`:123` `分 < 60` ⇒「%1分钟前」；
`:129` `时 = 分/60`，`< 24` ⇒「%1小时前」；`:136` 再往下印 `%1天前`（`时/24`）。**全是整数除、逐级取整**
⇒ 换算成阈值就是 `<60` / `<3600` / `<86400`，但**代码里没有这三个常数**，抄成 `if 秒 < 3600` 那种写法在
