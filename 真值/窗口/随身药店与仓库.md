# 随身药店 / 随身仓库（背包底部两枚钮 + 「购买VIP确认」弹）—— 逐件真值

体检 #46。这两枚钮以前一枚躺在占位话表里（药店）、一枚是**本地抢开窗**（仓库：
`会话.request_feature("NPC仓库")`，一个包都不发）。改完的口径：**点击只发一跳，开窗的是回帧**。

## ① 四支判式（两支 handler 只差**窗名**与**动作号**，其余逐字同）

| 支 | 条件（AS3 原文） | 药店 | 仓库 |
|---|---|---|---|
| ① | `API.ui.content.shopWindow` / `.storageWindow` 真 | `reverseDisplay(SHOP_WINDOW2_F)` ⇒ **切显隐，一个包都不发** | 同左，`STORAGE_WINDOW2` |
| ② | `API.waiGuaHandler.isConnected` | `requestVip_openMedicineForWaSai` = `1818:3` | `..._openStoreForWaSai` = `1818:4` |
| ③ | `VIPManager.vipLevel >= CANG_KU_LEVEL` | `requestVip_openMedicine` = `1818:1` | `requestVip_openStore` = `1818:2` |
| ④ | else | `showBuyVIPConfirmWindow(按钮文字)` ⇒ 点「开启」后走元宝那条 | 同左 |

- **① 判的是"实例建过没有"，不是"窗开着没有"**：`IUIMain.as:6` 的 getter 读的是
  `UIMain2.as:3004 / :2584` 的 `this._windowMap[...]`；`reverseDisplay:5143` 再看 `contains()` 决定
  remove 还是 create。⇒ 本工程用 `窗口管理.取窗口(页名) != null`，命中后 `打开或收起`。
  **本地抢先把空页开出来 = 把上次那帧的旧货架糊玩家一脸**，这就是修前仓库那枚的病。
- **② 整支不移植**：本工程没有 `WaiGuaHandler`（自动购买/自动挂机）那半边。代码里注释钉死，
  别哪天照 AS3 把它"补回来"。
- `CANG_KU_LEVEL = 1`（`vip/VIPManager.as:15`，药店仓库共用这一个常量，不是两个）⇒ `仓库等级 := 1`。
- ④ 的余额闸 `DataCenter.cashMoney < 2`（`ItemWindow2.as:379 / :397`，**两支都严格小于 2**）；
  不足只 `addNotice(...)` 那句 = **`很抱歉，你的元宝不足！`**（`:1420`），不发包。
  ⚠ 顺序：`clickOkBtnHandler:60-74` 先调 `_okFun`（:66/:70）、**后** `this.destroy()`（:73）
  ⇒ 那句 notice 是在**弹还没关**的时候喊的，而弹无论如何都会关（回调里 return 也拦不住 :73）。
  本工程照抄这个顺序：余额不足 ⇒ 通告出一条、`1818` 零条、**弹照样 free**。
