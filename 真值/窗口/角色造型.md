## ① 原版机制：只有一个入口 = 服务端下发的 `face`

| 画的时候 | 只从 `skinObj[动作名][帧号].body.value.className` 取图 | `CharacterSprite.as:1538-1568 render()` |

| 头像（PortraitHead） | **同一个 face**：`_loc6_.skin = charLook.face` | `CharacterHandler.as:305-307`、`PortraitHead.as:136` |

## ③ 服务端那一头怎么算 face（本工程已实现，本轮只修了一处反义）

`服务端/runtime/tools/fake_flash_server.py`：

| 档 | 算式 | 行 |
|---|---|---|
| 变身优先 | 变身卡（`use_type == "bianshen"` 的 `parameters.face`）> 变身装备位 `EquipmentPosition.TRANSFORM` 的 `definition.face` | `:17498 _current_character_face` |
| **没穿任何身体装备 ⇒ 裸体两套** | 水/风（200/400）→ `2`；火/雷（100/300）→ `1`；职业也不是这四个时按 `gender`（**2=女 / 其余=男**） | `:17545 _base_character_face` |
| 穿了 ⇒ `职业 + (身上最高需求等级 ≥ 40 ? 3 : 0)` | 即 `100/103`、`200/203`、`300/303`、`400/403` | 同上 |
| 推给客户端 | `UPDATE_CHAR_LOOK = 199`，字段里带 `gender / skinColor / face / myEquipments / lingFace` | `:17590 _send_character_look`、`ServerOpcode:837` |

> `ignored_positions`（武器/变身/特殊/徽章/坤虫四格+袋）**不参与**换装判定 —— 只算真正穿在身上的身体件。

**本轮修掉的一条真缺陷**：裸体兜底那一行写的是
`NAKED_FEMALE if gender == 1 else NAKED_MALE` —— 与 `MAIL=1(男) / FAMAIL=2(女)` **正好反了**，
男角色会被判成女身。改成 `gender == 2` 才给女身（`gender == 0` = 老存档没写过 ⇒ 按男，
与创角窗默认停在第一格「火男」一致）。门里第 ⑤ 腿把它钉死。

## ④ 本工程真正的 bug 与修法

`脚本/角色/玩家.gd`：`setup_player_sprite()` 里 **`configure("character", "00000001", "stand")` 写死**，
完全没读 `face` ⇒ 服务端算得再对也白算，**女角色进游戏也是金发男**（用户实机报的第 4 条）。
远程玩家那头本来就在用 face（`地图实体.gd:269` `str(int(state.get("face",1))).pad_zeros(8)`）——
本地玩家是唯一没接上的。

改：
- 新 `脚本/角色/角色造型.gd`：`造型号(脸, 性别)` = `脸 > 0 ? pad_zeros(8) : 兜底(性别)`；兜底只分男女。
- `玩家.gd`：新增 `_自身外观()`（在线读 `BackendConnection.authoritative_stats` 的 `face/gender`、
  离线读 `GameSession.player_stats`），`setup_player_sprite()` 用它。
  ⚠ `_ready` 里 `setup_player_sprite()`（:121）跑在 `_backend` 赋值（:122）**之前** ⇒ 必须自己 `get_node_or_null`。

### 三条会复发的

1. **在线用例走独立端口，就必须自己写回 `game_settings.backend_port`**：夹具只把端口号放进环境变量
   `NARUTO_SERVER_PORT`，而客户端读的是存档里的 `backend_port`（`后端连接.gd:517`）⇒ 不写回就连默认口 18684，
   表现为「离线 - 连接超时」（本轮第一次跑就是这么红的，10-12）。收尾只还原那一个键，别整份覆盖。
2. **「贴图没变」不等于「没坏」**：`configure` 对不存在的号是先清 `actions` 再返回 false，
   所以只钉 `texture.resource_path` 的判据会放过一个把动画表清空的变异（W1）⇒ 观测点要带上"还能不能换帧"。
3. **199 的文本→二进制那一段字段错位**（`fake_flash_server.py:61241-61270`）：给原版线格式客户端编码时把
   `fields[11]`（灵气脸）放进了 `itemEffect` 槽 ⇒ 本工程读文本包不受影响，**未修**（要动服务端，等点头）。
