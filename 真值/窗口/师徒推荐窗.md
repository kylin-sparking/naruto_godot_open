### 高度算式（`doLayout()` 整段，n = 说明文折行后的行数）

```

面板底.y = 49 + 条高                   # :117
黄底高 = 条高 + 172 + 15               # :118
钮.y   = 39 + 黄底高 + 5               # :124
窗高   = 钮.y + 22 + 5                 # :127  background.height
```

## ③ 数据形状与"为什么行里必须有职业"

原版 `setData():135-155` 读的是 AMF 对象：`{tutors:[{charId,name,level,job,face,...}], online:int}`
/ `{students:[...], count:int}`（`UIMain2.as:5088` 那一份形状）。本机服务端发的是**文本帧**（§⑥），
一行五段：`名&号&脸&等级&职业`。

⚠ 行件要 5 个字段（`charId/name/level/job/face`），而服务端 `_tutor_recommended_row:22444-22454`
原来只拼了 **4 段**（`名&号&脸&等级`，没有职业）⇒ 光靠它画不出「等级+职业名」那一行。
本轮按授权补齐协议：给它**追加第 5 段 job**（§⑥）。
