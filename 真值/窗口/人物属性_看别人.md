## ⑥b 他的**装备格**是另一套数（2026-10-22 补，用户报修「看别人装备格缺品质/绑定角标」）

原版**两套数**这条是硬事实，不是优化：`CharOtherWindow2.as:194-204 initWindow()` 逐路喂
`UIConfig.otherEquipData / otherShenqiData / otherHunjieData / otherLingQiData / otherRenJuData`
给 `equipPane`，而自己那扇读的是 `API.dataCenter.equippedItems`。同一支 `setSeriesIcon` 里
这个分叉写得最直白（`EquipPane.as:853`，分支在 `:872-879`）：

else                _loc2_ = param1;          // ← 看别人：用**传进来的**他的数组

（`他人装备串键`）走**同一个** `_parse_item_list` → `_parse_item_entry`，按 `equip_position`
（**协议里那个负数**，不是 1 基下标）合成一张 `{位置 → 物品}`，落在 `他人详细信息["装备"]`。
